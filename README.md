# 🚗 LOCALIZA Cars In .NET

A study project developed in **C#** and **.NET**, simulating a vehicle rental system.

The main objective of this project is to practice object-oriented programming, software architecture and modern .NET development concepts while building a realistic business application.

---

## 📚 Features

- Customer management
- Vehicle management
- Vehicle rental
- Rental cancellation
- Vehicle return
- Rental price calculation
- Rental validation

---

## 🏛️ Architecture

The project follows a layered architecture.

```
LOCALIZACarsInDotNet
│
├── Entities
├── Enums
├── Interfaces
├── Services
└── (Repositories - WIP)
```

Current focus:

- Object-Oriented Programming (OOP)
- SOLID principles
- Interfaces
- Service Layer
- Repository Pattern
- Clean Architecture concepts
